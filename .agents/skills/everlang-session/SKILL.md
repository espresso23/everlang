# EverLang session

Locate the user's EverLang checkout. Read AGENTS.md and documentation/workflow/NEW_SESSION.md. Inspect branch/status and the scoped diff without resetting, stashing or transferring uncommitted work. Read the newest relevant HANDOFF entry and the issue's context packet; load additional history only if necessary.

Establish the assigned issue, outcome, settled decisions, authorization and next uncompleted action. Reconcile checkpoint claims with actual files and evidence. Do not assume a prior test result applies after code changed or a feature is complete because a HANDOFF summary says implemented.

Read only the PRD/technical contracts and dependencies needed for that issue; use focused search instead of loading the entire repo. If no task was assigned, ask for the concrete objective without starting the backlog. Follow the workflow's skill routing when scope needs refinement or execution.

Keep context below the project's approximate internal budget when observable; never claim a universal model smart-zone threshold or invent token telemetry. Before a user-requested reset or suggested fresh chat, write a durable packet from documentation/templates/workflow/context.md and link it in HANDOFF. Include pre-existing edits, performed checks, limits, blockers and exact next step, without secrets. Do not clear/delete/archive a chat on your own.

If automatic compaction has already occurred, continue from the packet and current repository state; do not restart completed work or require the user to reconstruct the history. Finish with the next concrete action inside the existing task scope.
